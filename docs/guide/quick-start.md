# Quick Start

Get started with the reposell listing in minutes.

## For Buyers

1. Browse the [listing catalog](https://listing.reposell.dev)
2. Click on a verified tool to see its details and pricing
3. Click "Unlock discovery" to purchase via Stripe Checkout
4. Receive your cryptographic license instantly

## For Sellers

1. Initialize your repository with the reposell CLI:
   ```bash
   npx @reposell/cli init
   ```
2. Configure your sell endpoint:
   ```bash
   npx @reposell/cli sell
   ```
3. Enable listing registration:
   ```bash
   npx @reposell/cli listing enable
   ```
4. Submit a pull request to the listing registry

## For Listing Operators

1. Register your instance with the official listing
2. Deploy your own listing frontend
3. Federate the product catalog from the official registry

See the [community listing guide](https://community.reposell.dev) for deployment instructions.
