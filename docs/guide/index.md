# Guide

The official reposell listing — discovery, purchase, and licensing of repository tools with cryptographic trust.

## What is the reposell Listing?

The reposell listing is the authoritative discovery directory for verified repository tools. It provides:

- **Product discovery** via verified `/listing` manifests
- **Repository registration** with Ed25519 signature verification
- **Stripe Checkout purchases** with instant cryptographic license issuance
- **Transparent pricing policies** with signed fee splits
- **Public listing network** registration

## How It Works

1. **Sellers** publish tools by registering their repository with a `/sell` endpoint
2. **CI verification** validates every listing against the seller's live endpoint
3. **Buyers** discover tools, verify signatures, and purchase with instant license issuance
4. **Listing operators** can deploy public instances that federate from the official registry
