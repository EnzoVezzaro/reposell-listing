# Product

## Register

brand

## Platform

web

## Users

**Primary**: Developers discovering and purchasing repository tools — they browse, evaluate, buy, and manage licenses. Technical, value verification and transparent pricing.

**Secondary**: Tool authors publishing to the listing — need onboarding, pricing policy management, webhook configuration, revenue tracking.

**Listing Operators**: Running public instances — need registration, compliance, settlement reporting.

## Product Purpose

The official reposell listing — discovery, purchase, and licensing of repository tools with cryptographic trust. Features:
- Product discovery via verified `/listing` manifests
- Repository registration with Ed25519 signature verification
- Stripe Checkout purchases with instant cryptographic license issuance
- Transparent pricing policies with signed fee splits
- Public listing network registration

## Positioning

**Discover verified tools. Publish with cryptographic trust. Transparent revenue by protocol, not platform.**

## Conversion & proof

- **Primary CTA**: Start Exploring → browse verified tools
- **Secondary CTA**: Publish Your Tool → zero-config seller onboarding
- **Tertiary CTA**: Deploy Public Listing → for operators
- **Belief ladder**:
  1. Verified tools save evaluation time
  2. Cryptographic signatures mean no fake/spam listings
  3. Signed pricing policies = no hidden fees
  4. Instant licenses = no manual fulfillment
  5. Public listing network = decentralized discovery

## Brand Personality

Technical, trustworthy, developer-first, transparent.

**Reference (user-named):** [soundcn.xyz](https://www.soundcn.xyz) — warm-orange shadcn/ui energy: stone neutrals, playful motion, developer-tool warmth. All three reposell sites share this visual language.

## Anti-references

- Generic listing templates (Product Hunt clones)
- Hidden fee structures
- Manual license fulfillment
- Centralized curation without protocol verification

## Design Principles

1. **Verification visible** — Every listing shows signature status, policy hash, verification timestamp
2. **Pricing transparent** — Fee splits shown before purchase, signed by policy
3. **Density with search** — Developers scan lists; filterable, sortable, keyboard-navigable
4. **Dark mode native** — Terminal aesthetic for late-night browsing
