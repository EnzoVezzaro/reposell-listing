# reposell Listing (Official)

The official reposell listing — a static discovery directory with verification CI and discovery payments.

**No server, no database, no Docker.** Pure static frontend + GitHub Actions CI + Stripe automation.

## Features

- **Product discovery** — browse and search products across registered repositories
- **Two-step purchase** — discovery contribution (reposell) + license purchase (seller)
- **Verification CI** — every listing PR verified fail-closed against the seller's live `/sell` page
- **Discovery payments** — per-release Payment Links created by CI (buyer-paid, seller keeps 100%)
- **Signed pricing policy** — cryptographically verified fee structure
- **Federation snapshot** — machine-readable `federation/v1/snapshot.json` for community instances
- **Community Discussion** — GitHub Discussions per listing for buyer community
- **Listing detail pages** — per-listing pages with repo info, README, and purchase flow
- **Payment link validation** — CI validates all Stripe payment links are active; frontend blocks buttons for invalid links
- **GitHub Device Flow** — connect GitHub account before payment (zero-server, no client secret)
- **Stripe redirect after payment** — buyers return to listing page with `?session_id` confirmation
- **README display** — full markdown README shown from listing record (no GitHub API calls)


## Documentation site

```bash
npm run docs:dev      # local dev server (auto-rebuilds index)
npm run docs:build    # production build
npm run docs:preview  # preview production build
```

The docs site is built with VitePress. The public index at `docs/public/registry/listings.json` is auto-generated by `scripts/build-listings-index.mjs` during every build.

## CI Workflows

### `discovery-sync.yml` (post-merge)

Runs after every merge to `main` that touches `listing/`:

1. **Promote** merged PR payloads into canonical registry records
2. **Provision** immutable discovery Payment Links via Stripe API
3. **Validate** all payment links are active via Stripe API (marks inactive links)
4. **Create Discussions** for new listings
5. **Regenerate** the public index (`docs/public/registry/listings.json`)
6. **Commit** all changes back to the repository

### `verify-pr.yml` (on PR)

Verifies every listing PR fail-closed:

1. Fetches the seller's live `/sell` page
2. Validates the embedded `reposell-data` JSON schema
3. Verifies repository identity, release availability, and Stripe Payment Link
4. Derives the registry record and commits it to the PR branch
5. Auto-merges on PASS, labels BLOCKED on failure

### `registry-event.yml` (repository_dispatch)

Event-driven registry mutation for the official reposell publisher:

- `listing.created` — writes registry record + creates Discussion thread
- `listing.updated` — replaces registry record
- `listing.unpublished` / `listing.deleted` — removes listing
- Regenerates federation snapshot + events log after every mutation

### `deploy-docs.yml` (on push to main)

1. Installs dependencies
2. Regenerates the public index
3. Builds the VitePress docs site
4. Deploys to GitHub Pages at `listing.reposell.dev`

## Fee Model

```
Product Price:        $50.00
Discovery Fee:        $5.00   (buyer-paid, on top of seller's price)
─────────────────────────────────────
Total Buyer Pays:     $55.00

Seller Keeps:         $50.00  (100% of their /sell price)
Reposell Gets:         $5.00  (the discovery contribution)
```

The seller keeps 100% of their `/sell` revenue. The discovery contribution is a separate transaction to reposell's Stripe account, created automatically by CI.
